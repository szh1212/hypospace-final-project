# 因果图实验结果

在同一个 Qwen2.5-3B 模型上，8 道测试题的平均恢复率从官方提示的 0.13% 提升到结构轮转的 21.51%。
自适应结构调度为 21.52%，相对固定轮转的差异仅 0.009 个百分点。
该结果支持显式结构探索，调度规则本身的额外收益仍缺乏证据。

## 提升来自哪里

- 对同一批题明确列出干预源必须到达和必须避开的节点，去除含具体边的示例，压缩重复历史。
  这一组提示改动使 V 提升 56.64 个百分点。当前消融没有分离组内各项措辞的独立作用。
- 下一次请求指出上一张图遗漏或错误连通了哪些节点，R 从 7.48% 提升到 12.15%。
- 对观测允许的边轮流要求包含或排除，R 从 12.15% 提升到 21.51%，同时 V 降到 42.58%。
- 自适应策略的全部 256 次测试提案都附加了结构条件。相对官方提示，8/8 题的 R 均有提升。
  逐题配对差为 +21.39 个百分点，观测级 bootstrap 95% 描述性区间为 [+12.04,+30.99]。
  相对固定轮转的配对区间为 [−5.64,+5.17] 个百分点。4 次和 8 次调用时固定轮转领先。
- 按每个题目与种子中六种直接生成方法的最低总 token 数截取前缀，固定轮转和自适应的 R
  分别为 21.17% 和 19.42%，官方为 0.13%。这是事后等 token 上限分析。
- 合法改边法先从题面构造起始图，再用公共约束筛选局部邻居，模型或随机选择器从中选一步。
  同一预算下随机选择达到 59.49%，高于模型的 46.84%。模型相对随机的配对区间为
  [−32.60,+7.84] 个百分点。混合系统的高恢复率包含了确定性验证、菜单构造和回溯的贡献。

## 数据与边界

- 测试含 8 个新的观测 ID，四个节点、最多四条边。节点重命名后共 6 种题型，2 种未在旧题出现。
- 样本较小，区间按 8 个观测 ID 重抽样，不能视为对所有图规模或独立题型的总体估计。
- 7 个使用模型的方法共 2,016 次真实推理，其中开发 224 次、测试 1,792 次。随机对照另有 288 次符号选择。
- 旧 3D 的原始数据与此实验任务不同。[原仓库数据与方法说明](causal-methods.md)
- 144 个方法/题目/种子单元、2,304 个候选均已重放，三个预算点的 V/U/R 与独立可达性检查一致。
- 开发、测试共用冻结的生成提交 5ecccf9。原始调用和响应保存在本地 runs/main-dev 及 runs/main-test。
