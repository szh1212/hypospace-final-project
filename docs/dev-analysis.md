# 真实开发集排查

官方prompt准确传递3×3观测与最大高度，但将无关四角结构作为示例，并用长文本说明约束。行代表网格中的行，Layer序号代表高度；两者混淆或模仿示例会使投影不匹配。已知合法结构穷举核验2619个均通过parser roundtrip和validator，故V=0不是所有合法答案被评价器误拒。评价器已知高度边界漏洞仍须报告。

9次原始生成均可解析但投影不匹配；去示例9次仍V=0，且3次截断。Structured方案明确每行的空间意义、Layer1必须复制观测、上层须为下层子集，并禁止长解释：两组dev共18次均有效，但重复严重。Coordinates首组V=1、第二组V=1/3，说明增加坐标并不稳定改善。Reasoning首组V=1，覆盖未胜出，且生成更长。Grounded底层直接给定方案两组也有投影错误。真实指标及资源见dev-study.json。

这些结果支持小模型能完成单格和Layer输出，提示方式有显著关联，但未将组合变化彻底做全因子因果分解。最终选择Structured，避免为了单次dev高覆盖选不稳定方案；下一步在固定测试集测真实泛化。不得基于正式结果重新调参。
