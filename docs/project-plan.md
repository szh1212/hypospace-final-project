# Project plan

## Four starting tasks

Each member claims one row by replacing `Unclaimed` with their GitHub username in a PR. Another member reviews the claim and later deliverables. All tasks are currently unstarted; execution waits until the team agrees on the experimental plan.

| Task | Owner | Initial deliverable |
| --- | --- | --- |
| Run the official baseline | Unclaimed | First document setup requirements and a proposed minimal run; after protocol approval, reproduce the baseline and record the upstream commit and commands. |
| Design an improved method | Unclaimed | Propose a novel approach, its motivation, expected effect on V/U/R, and a minimal ablation plan. |
| Build evaluation and result recording | Unclaimed | Plan integration with official validators, check metric definitions, and define comparable budgets and a result schema. |
| Prepare reproduction instructions and presentation materials | Unclaimed | Draft reproducibility documentation, reference tracking, and an outline for the final report and presentation. |
