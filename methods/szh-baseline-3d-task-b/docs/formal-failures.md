|类别（次数）|Original|Adapted|
|---|---:|---:|

|俯视图不符|585|136|
|俯视图正确但缺少支撑|0|0|
|通过官方验证，含重复|0|448|
|其中，错误俯视图恰为示例的四角图案|313|0|

前四行互斥，最后一行是投影不符的子集。四角均被占用的投影不可能匹配本测试集的 1–3 个占用格；该计数描述输出中的图案，不能单独证明示例导致了错误。合法输出中的重复情况见两组 metrics.json 的 failure_categories。
