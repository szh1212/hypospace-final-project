# 实验结果：两级分层 + 有效性过滤 vs 基线（3D 体素重建）

方法：`kevin/3d-twolevel-stratification` 分支的 Kevin 两级分层 + 有效性过滤（四代演进的最终
第 4 代）。实验条件与 SZH 基线逐项对齐：同数据集（sha256 `61cebef…`）、同 15 题测试集、
同种子 17/42/2026、同预算（每题 3^b 次调用，共 585 次）、同模型与采样参数、同一官方评测器
（上游 `c69e931`）——**仅方法不同**，全部比较在相同 (题, 种子, 预算) 上配对。所有数字均可由
`experiments/audit_3d.py` 从本地原始调用记录重放核对（8 个运行共 12,156 项检查、0 失败）。
